# Lecture 2: Combinational Logic

## Introduction and Review
This lecture builds on the basics of digital design and transistor-level logic introduced earlier. It focuses on how logic gates combine to form larger functional systems.

## Transistors and Logic Gates

### Transistor Abstraction
Transistors act as simple switches that control electrical signals. In digital design, they are abstracted into binary behavior (ON/OFF) to build logic circuits.

### CMOS Logic Gates
CMOS technology uses both NMOS and PMOS transistors together to create efficient logic gates with low power consumption and high reliability.

### Series vs. Parallel Transistors
- Series configuration: Both inputs must be active for current to flow (AND behavior) 
- Parallel configuration: Either input can activate the circuit (OR behavior)

### Power Consumption
Power in digital circuits depends on switching activity, capacitance, and voltage. CMOS reduces static power by ensuring minimal current flow in steady states.

## Moore's Law and Scaling
Moore’s Law states that the number of transistors on a chip approximately doubles every two years, leading to increased performance and reduced cost per transistor. However, physical limitations are making scaling more challenging.

## Combinational Logic Circuits: Fundamentals

### Functional vs. Timing Specification
- Functional specification defines what the circuit does 
- Timing specification defines how quickly the circuit responds

### Definition of Combinational Logic
Combinational logic circuits produce outputs based only on current inputs, without any memory or feedback.

## Boolean Algebra

### Laws and Theorems
Boolean algebra provides rules for simplifying logic expressions, such as identity, null, idempotent, and distributive laws.

### Canonical Representations
Logical expressions can be represented in standard forms like SOP and POS for easier analysis and design.

### Sum of Products (SOP)
SOP is a form where multiple AND terms are ORed together to represent a logic function.

### Min-term Notation
A minterm is a product term that represents exactly one combination of inputs where the function is true.

## Advanced Logic Representations and Simplification

### Product of Sums (POS)
POS is a form where OR terms are ANDed together to represent a logic function.

### Max-term Notation
A maxterm represents a sum term that corresponds to a single input combination where the function is false.

## Combinational Building Blocks

### Decoders
Decoders convert binary input into a one-hot output representation.

### Multiplexers
Multiplexers select one input from many based on select signals.

### Binary Adders
Binary adders perform arithmetic addition of binary numbers.

### Ripple Carry Adder
A ripple carry adder connects multiple full adders where carry propagates from one stage to the next.

### Programmable Logic Arrays (PLA)
PLAs are configurable hardware structures used to implement combinational logic efficiently.
