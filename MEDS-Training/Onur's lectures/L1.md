# Lecture 1: Introduction to Computer Architecture

## Course Logistics and Information
This course introduces the fundamentals of computer architecture, covering how modern computing systems are designed from basic hardware to advanced memory and processing systems. It also builds the foundation for understanding performance, design trade-offs, and system-level thinking.

## Technical Fundamentals: Why Do We Use Computers
Computers are used to process data efficiently and accurately at large scale. They automate tasks that would be slow or impossible for humans, such as simulations, data analysis, and real-time decision-making.

### Defining Computer Architecture
Computer architecture refers to the structure and behavior of a computer system. It defines how hardware components interact and how instructions are executed at the lowest level.

### Computing Platforms and Examples
Computing platforms include personal computers, smartphones, servers, and embedded systems. Each platform is optimized for different workloads, such as performance, energy efficiency, or portability.

### Specialized Accelerators
These are hardware units designed for specific tasks like graphics processing (GPUs), AI workloads (TPUs), or signal processing. They improve speed and efficiency compared to general-purpose CPUs.

### Future Systems: Genome Analysis and PIM
Future computing systems focus on data-intensive tasks like genome analysis. Processing-In-Memory (PIM) reduces data movement by performing computation closer to where data is stored, improving performance and energy efficiency.

## Digital Design Fundamentals
Digital design is the foundation of computer hardware. It involves building systems using binary logic and electronic components.

### From General Purpose to Special Purpose
General-purpose processors can run many types of programs, while special-purpose hardware is optimized for a specific task. This trade-off balances flexibility and performance.

### Hardware Building Blocks
Digital systems are built using basic components like logic gates, registers, and flip-flops. These components work together to process and store information.

### Transistors
A transistor is a basic electronic switch used to control electrical signals. It is the fundamental building block of all modern digital circuits.

### The MOS Transistor
MOS (Metal-Oxide-Semiconductor) transistors are widely used in modern chips. They come in two types: NMOS and PMOS, which control current flow in different ways.

### N-type and P-type Transistors
- N-type (NMOS): Conducts when voltage is high 
- P-type (PMOS): Conducts when voltage is low 
Together, they form efficient switching circuits.

### Wall Switch Abstraction
A transistor can be thought of like a wall switch: it either allows current to flow or blocks it, similar to turning a light on or off.

### Introduction to Logic Gates
Logic gates perform basic operations like AND, OR, and NOT using transistors. These gates form the foundation of all digital computation.

### CMOS Gate Structure
CMOS (Complementary Metal-Oxide-Semiconductor) uses both NMOS and PMOS transistors together to build efficient logic gates with low power consumption.
