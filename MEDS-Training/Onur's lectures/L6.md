# Lecture 6: Timing & Verification II

## Combinational Circuit Timing

### Propagation vs. Contamination Delay
Propagation delay is the maximum time taken for a signal to travel through a circuit and stabilize at the output. Contamination delay is the minimum time after which the output may start to change.

### Definitions
- Propagation delay: Worst-case delay from input to stable output 
- Contamination delay: Best-case delay from input to initial output change 

### Longest and Shortest Delay Paths
- Longest path determines maximum operating frequency (critical path) 
- Shortest path affects hold time constraints 

### Factors Affecting Propagation Delay
Delay depends on gate complexity, fan-out, interconnect length, and load capacitance.

### Voltage and Temperature Dependencies
Higher temperature and lower voltage increase delay, reducing circuit speed.

### Implementation Differences
Different logic implementations of the same function can have different timing characteristics.

## Glitches

### Definition
A glitch is a temporary incorrect output caused by unequal propagation delays in logic paths.

### Causes
Glitches occur due to changes in input signals arriving at different times in combinational logic.

### When to Avoid Glitches
Glitches are critical in clocked systems and control signals where incorrect transitions can cause errors.

## Sequential Circuit Timing

### Setup and Hold Time Constraints

### Definitions
- Setup time: Minimum time data must be stable before clock edge 
- Hold time: Minimum time data must remain stable after clock edge 

### Setup Time Constraint
Ensures data arrives early enough to be captured correctly by flip-flops.

### Hold Time Constraint
Ensures data does not change immediately after being captured.

### Clock Skew

### Definition and Impact
Clock skew is the difference in arrival time of the clock signal at different flip-flops.

### Effect on Setup and Hold Times
Clock skew can either relax or tighten timing constraints depending on direction.

## Circuit Verification

### Overview of Challenges
Verification ensures that a design works correctly under all input conditions and timing scenarios.

### Functional Verification
Checks whether the circuit performs the intended logical function.

### Test Benches and DUTs
A testbench is used to apply inputs to the Device Under Test (DUT) and observe outputs.

### Types of Test Benches

#### Simple Manual Test Bench
Applies fixed inputs manually to check basic functionality.

#### Self-Checking Test Bench
Automatically compares outputs against expected results.

#### Test Vector File-Based
Uses external files to feed input patterns to the design.

---

### Timing Verification
Ensures the design meets timing constraints under real hardware conditions.

### High-Level Modeling
Abstract models are used to simulate system behavior before hardware implementation.

### Tools for Timing Analysis
EDA tools analyze delays, critical paths, and timing violations.

### Fixing Timing Violations
Timing issues can be fixed by optimizing logic, balancing paths, or inserting pipeline stages.

---

## Design Principles

### Critical Path Optimization
Improving the longest delay path improves overall system speed.

### Balanced Design
Ensures all paths have similar delays to avoid bottlenecks.

### Optimize for Common Case
Design should be optimized for the most frequently used operations rather than rare cases.
