# Lecture 3: Sequential Logic

## Combinational Logic Completion

### Programmable Logic Array (PLA)
A PLA is a configurable device used to implement combinational logic functions using programmable AND and OR arrays. It allows flexible mapping of logic expressions into hardware.

### Other Combinational Blocks

### 4-Bit Comparator / Equality Checker
A comparator checks whether two binary numbers are equal, or determines which one is greater. A 4-bit comparator compares two 4-bit inputs bit by bit.

### Arithmetic Logic Unit (ALU)
An ALU is a core processor component that performs arithmetic (add, subtract) and logical (AND, OR, XOR) operations based on control signals.

### Tri-State Buffer
A tri-state buffer can output 0, 1, or high impedance (Z). The high impedance state allows multiple devices to share a common bus.

#### Multiplexer Implementation with Tri-State Buffers
Multiplexers can be built using tri-state buffers by enabling only one input at a time onto a shared output line.

#### 2-to-1 Multiplexer
A 2-to-1 multiplexer selects between two inputs based on a single select signal.

#### 4-to-1 Multiplexer
A 4-to-1 multiplexer selects one of four inputs using two select lines.

#### Tri-State Buffer Transistor-Level Implementation
At the transistor level, tri-state buffers use controlled gating to disconnect output when disabled.

### Boolean Algebra Simplification
Boolean expressions can be simplified using algebraic rules to reduce hardware complexity and improve performance.

### Automated Simplification
Tools like Karnaugh maps and Quine-McCluskey algorithms automate logic minimization.

### Priority Circuit
A priority circuit selects the highest-priority active input when multiple inputs are active.

## Sequential Logic

### Cross-Coupled Inverters
Cross-coupled inverters form a basic memory element that stores one bit of information.

### Storage of Data
Sequential circuits store data using feedback, unlike combinational circuits which do not have memory.

### Memory Hierarchy Overview
Memory systems are organized in levels: registers, cache, main memory (DRAM), and secondary storage, balancing speed and capacity.

### SRAM, DRAM, and Other Technologies
- SRAM: Fast, expensive, used in cache  
- DRAM: Slower, dense, used in main memory  

### RS Latch
An RS latch is a basic memory element built using NOR or NAND gates that stores one bit.

### NAND-based RS Latch
A variation of the RS latch implemented using NAND gates with active-low inputs.

### Gated D Latch
A gated D latch stores input data only when the enable signal is active.

### Register Design
Registers are groups of flip-flops used to store multi-bit data.

### Memory Array Design
Memory arrays organize storage cells in rows and columns with decoding logic for addressing.

### Addressing and Read/Write Operations
Memory is accessed using addresses to read or write data into specific locations.

### Lookup Tables (LUTs) and FPGAs
LUTs are programmable memory blocks used in FPGAs to implement logic functions.

### Finite State Machines (FSM)
FSMs are models used to design sequential systems with defined states and transitions.

### Concept of State and State Diagrams
A state represents a system condition, and state diagrams show transitions between states.

### Formal Definition of FSM

#### Components of FSM
An FSM consists of states, inputs, outputs, transition functions, and an initial state.

#### Next State Logic, State Register, Output Logic
- Next state logic determines future states  
- State register stores current state  
- Output logic generates outputs based on state

### Synchronous Systems and Clocking
Synchronous systems use a clock signal to coordinate changes in state across the system.

### Edge-Triggered Flip-Flops
Flip-flops store data on clock edges (rising or falling), ensuring stable and synchronized operation.
